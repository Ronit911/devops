## Why Docker

Traditional application deployment can depend heavily on the configuration of the machine where the application runs.

Docker helps package an application together with its required runtime and dependencies into a container image.

This makes application environments more consistent between development, testing, and deployment.

## Related Areas

Docker connects directly with:

- GitHub and CI/CD
- Nginx
- Self-hosted runners
- Production deployment

The objective is to understand Docker as part of a complete deployment workflow rather than as an isolated tool.
