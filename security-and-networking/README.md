
# Security and Networking

This section documents my learning and hands-on work around network connectivity, access control, and troubleshooting connectivity failures.

## Topics Covered

### 1. Windows SMB Server and Client Connectivity
Understanding how a Windows client connects to an SMB shared folder, how network connectivity is verified, and how server configuration and permissions affect access.

[Read the documentation](smb-server-client-connectivity.md)

### 2. Internet Outage and Cloudflare Tunnel
Understanding the dependencies of Cloudflare Tunnel, what happens when internet connectivity is lost, and why a separate local network path may be necessary for continued access.

[Read the documentation](internet-outage-and-cloudflare-tunnel.md)

### 3. Zero Trust and Application-Aware Firewall
Learning how Zero Trust principles and application-aware access controls can restrict network access to selected applications and destinations.

[Read the documentation](zero-trust-app-aware-firewall.md)

## Learning Approach

For each topic, I focus on understanding how the technology works, configuring and testing it, troubleshooting issues, and documenting the behavior and limitations I observe.

The goal is to understand the dependencies between networking, security policies, server services, and remote access rather than treating each component independently.
