# PM2 Process Management

PM2 was used to manage the running application process on Ubuntu Server.

## Why PM2?

When an application is started directly from an SSH session, the process may stop when the session ends or when the process terminates.

PM2 provides process management for Node.js applications.

It can:

- Keep applications running
- Restart applications when they crash
- Run applications in the background
- Provide process monitoring
- Manage application logs
- Restart applications after server restarts when configured

## Installation

PM2 can be installed globally using npm:

npm install -g pm2

## Starting an Application

An application can be started with:

pm2 start <application>

For a named process:

pm2 start <application> --name react-app

The process can then be checked with:

pm2 status

## Example Process

The deployment environment used a PM2 process named:

react-app

The PM2 process was observed in an online state while the application was running.

## Useful Commands

Check running processes:

pm2 status

View logs:

pm2 logs

Restart an application:

pm2 restart react-app

Stop an application:

pm2 stop react-app

Remove an application from PM2:

pm2 delete react-app

Display detailed information:

pm2 describe react-app

## Startup Configuration

PM2 can generate startup configuration so that managed applications can be restored after a server reboot.

The general workflow is:

pm2 startup
pm2 save

The exact startup command generated by PM2 depends on the operating system and user configuration.

## Role in the Deployment

PM2 sits between the application and the operating system process manager:

React / Node Application
        |
        v
      PM2
        |
        v
Ubuntu Server

This makes application process management more reliable than manually running the application from a terminal.
